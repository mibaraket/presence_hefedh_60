العودة إلى العرض التقديمي الذهاب إلى التطبيق الرئيسي

دليل المستخدم الشامل • منظومة حفظ الستين

مرحباً بك في الدليل الإرشادي الرسمي لـ منظومة متابعة حضور وتسميع حفاظ القرآن الكريم (مجموعة حفظ الستين). يهدف هذا المستند إلى توفير شرح وافٍ لكافة وظائف النظام، وأدوات الإدارة، وإجراءات التشغيل الآمن.

1. هيكل النظام والأبواب الخمسة الرئيسية

تم تصميم الواجهة بأسلوب Dark Luxury Emerald & Slate المريح للعين والمنظم في تبويبات رئيسية:

  • التسجيل والحضور (Check-in): تتيح تسجيل الحضور الفوري للطلاب إما بالضغط المباشر على بطاقة الطالب أو بإدخال رقم التعريف (ID). تعرض ألواناً مميزة (أخضر للحاضر، أحمر للغائب، أصفر للمتأخر).
  • جلسة التسميع (Recitation Queue): إدارة تسميع القرآن الكريم عبر نظام ثنائي المراحل (حفظ جديد ومتابعة / تكرار)، مع تحديد رقم الحزب أو الجزء، ومراقبة حالة كل طالب في الجلسة النشطة.
  • الاختبارات (Exams): إدارة الاختبارات الدورية والشهرية بإشراف المقرئ (الشيخ مراد الجدلي)، مع إدخال تفاصيل درجات الحفظ، أحكام التجويد، وحسن الأداء مع حساب المجموع التلقائي (من 100).
  • جدول الحضور الإجمالي (Attendance Table): جدول شامل يربط بين جميع الجلسات الأسبوعية (الأسبوع 1، 2، 3...) وحالة حضور كل طالب ومعدل نسبته المئوية.
  • قائمة الطلاب (Students Roster): قاعدة بيانات شاملة للـ 38 طالباً، تعرض تفاصيل الانتماء للفوج (فوج حفظ الستين)، حالة التثبيت، والقدرة على إضافة أو تعديل بياناتهم.

2. دليل إدارة الجلسات والأرشيف التاريخي

يضمن النظام حفظاً تاما لكافة السجلات التاريخية للجلسات الأسبوعية السابقة (مثل الأسبوع 1 بتاريخ 04/07/2026، والأسبوع 2 بتاريخ 11/07/2026، والأسبوع 3 بتاريخ 18/07/2026) بالإضافة إلى الجلسة اليومية النشطة.

ملاحظة هامة: عند إنشاء جلسة جديدة عبر زر "جلسة جديدة"، يتم أرشفة الجلسة الحالية وبدء جلسة جديدة نظيفة دون فقدان أي بيانات سابقة للأسبوع أو الطلاب.

3. صلاحيات المستخدمين (RBAC) والأمان

الدور (Role) اسم المستخدم الافتراضي الصلاحيات المتاحة
مدير النظام (Admin) admin التحكم الكامل، إدارة الحسابات، تعديل قاعدة البيانات، حذف وإضافة الجلسات والطلاب.
أستاذ / مقرئ (Teacher) teacher (أو الشيخ مراد الجدلي) إدارة الحضور، رصد التسميع، إدخال درجات الاختبارات، وتصدير التقارير.
مشاهد / مراقب (Viewer) viewer استعراض الجداول، نسبة الحضور، وسجلات التسميع دون صلاحية التعديل.

4. تصدير التقارير والطباعة

  • تصدير Excel: يمكنك بضغطة زر تصدير جدول الحضور والغياب والتسميع إلى ملف Excel متوافق مع كافة برامج الجداول الحسابية.
  • تقرير PDF: إنشاء تقرير رسمي مفصل ومنسق للطباعة أو المشاركة الفورية عبر البريد أو وسائل التواصل.

5. الأسئلة الشائعة واستكشاف الأخطاء (FAQ & Troubleshooting)

س: هل يعتمد التطبيق على أي واجهات ذكاء اصطناعي خارجية؟

ج: لا، التطبيق مستقل تماماً ومحلي بالكامل (لا يتطلب أي مفاتيح API خاصة بـ Gemini أو غيرها)، مما يضمن سرعة الفتح والخصوصية التامة للبيانات.

س: كيف يمكنني مزامنة البيانات عبر سحابة Supabase؟

ج: من خلال النقر على أيقونة قاعدة البيانات في شريط العنوان العلوي، يمكنك إدخال إعدادات الاتصال السحابي (Supabase URL & Anon Key) لمزامنة البيانات لحظياً عبر الأجهزة.

س: ماذا تفعل إذا واجهتك مشكلة في التخزين المؤقت للمتصفح؟

ج: يتم تخزين البيانات تلقائياً في التخزين المحلي (LocalStorage). يمكنك النقر على خيار إعادة تعيين البيانات الافتراضية من نافذة إدارة قاعدة البيانات لاستعادة الحالة الأصلية عند الحاجة.
